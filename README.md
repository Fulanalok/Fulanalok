## Projeto em destaque

### IngressosZ

Plataforma full stack para venda e validação de ingressos digitais.

- Autenticação de usuários
- Integração com Mercado Pago
- Armazenamento com Firestore
- Validação por QR Code
- Testes automatizados com Vitest e Cypress

**Stack:** React, TypeScript, Tailwind CSS, Firebase Auth, Firestore, Firebase Functions, Vitest e Cypress.
